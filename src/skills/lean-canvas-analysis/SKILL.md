# Skill: lean-canvas-analysis

# Lean Canvas Analysis Generator

Generate a comprehensive Lean Canvas analysis from micro-SaaS opportunity reports.

## Input

The user provides:
1. A **micro-SaaS opportunity report** generated by the micro-saas-opportunity skill
2. A **selection** of which proposed solution from the report they want to analyze

## Analysis Phase

### 1. Report Parsing

Extract key information from the micro-SaaS opportunity report:
- Market segment definition
- Proposed solutions (with their value propositions)
- Competitive landscape
- Revenue model
- Market opportunity sizing

### 2. User Selection

Identify which proposed solution the user selected and extract its:
- Target workflow
- Core features
- Differentiation points
- Technical complexity

## Lean Canvas Structure

Generate a single markdown document with this structure:

# Lean Canvas Analysis: [Solution Name]

**Based on**: [Original market segment] micro-SaaS opportunity report

**Selected Solution**: [Solution name] - [Brief value proposition]

## Quality Standards

The Lean Canvas analysis must:

1. **Align with original report**: All components must be grounded in the micro-SaaS opportunity data
2. **Be specific**: Avoid generic statements - use concrete details from the report
3. **Show reasoning**: Explain why each Lean Canvas element is positioned as stated
4. **Be actionable**: Provide clear next steps based on the analysis
5. **Maintain consistency**: Ensure the selected solution's value proposition matches across both reports

## Output

Deliver the complete Lean Canvas analysis as a single markdown document. The
document should be saved as a single markdown text file.
